# 完整流程：从采集到网页

一条链路，五步。每一步的产物只来自上一步，图和网页上的每个数都能追溯到数据库里的一条 SQL。

```
OpenAlex / ROR / World Bank ──采集──▶ PostgreSQL ──SQL──▶ CSV + PNG（PPT）
                                              └──SQL──▶ scholarscope.html（网页）
```

所有命令都在仓库根目录执行。数据库连接一律用 `127.0.0.1`，不要写 `localhost`（Windows 上会卡住）。

---

## 1. 起数据库

先打开 Docker Desktop，然后：

```bash
docker compose up -d --wait
```

`.env` 里要有 `POSTGRES_USER / POSTGRES_PASSWORD / POSTGRES_DB`（模板是 `.env.example`）。

## 2. 建库：两条路选一条

**A. 恢复现成的库（推荐，约 1 分钟）。** 从 Releases 下载 `scholarscope.dump`：

```bash
docker compose exec -T postgres pg_restore -U scholarscope -d scholarscope --clean --if-exists --no-owner < scholarscope.dump
```

**B. 从头采集（约 20 分钟，OpenAlex 约 $0.16）。** 需要在 `.env` 里填 OpenAlex 的 API key：

```bash
uv sync
uv run scholarscope migrate
uv run scholarscope ingest --profile standard
uv run scholarscope ror
uv run scholarscope worldbank
uv run scholarscope quality
```

各命令的作用、退出码和费用见 [`development.md`](development.md)。

两条路都要再补一次台湾（World Bank 没有台湾，重复执行无害）：

```bash
docker compose exec -T postgres psql -U scholarscope -d scholarscope < country_indicators_analysis/sql/00_add_taiwan.sql
```

## 3. 取数 + 出图（PPT 用）

```bash
uv run python analysis/run_all.py --strict
```

- 依次执行五个方向的脚本。每个脚本跑自己 `sql/` 下的查询（只读连接，不会改数据），
  把结果存成 `output/*.csv`，再画成 `output/*.png`（300 dpi，4000×2250）和 `*.pdf`。
- `--strict`：连不上数据库就报错。终稿必须这样生成。
- `--from-csv`：不连库，用已有的 CSV 重画，只用于调样式。
- 共 35 张图，样式规范见 [`../analysis/图表统一规范.md`](../analysis/图表统一规范.md)，
  每张图的含义和口径见各方向的 `README.md`。

## 4. 网页

```bash
uv run python site/build_site.py
```

- 连数据库，执行**和第 3 步同一批** `sql/*.sql`（外加 `site/sql/overview.sql` 的语料规模），
  把 35 张可交互图（Plotly）、数据和 plotly.js 一起写进 `site/dist/scholarscope.html`（约 6 MB）。
- 这个文件**双击就能打开**，不需要服务器、不需要联网，可以直接发给别人、放进 Release 或 GitHub Pages。
- 它是构建时刻的快照。数据变了就重跑这一步。
- 页面版式（Hallmark 设计）在 `site/template.html.j2` 和 `site/tokens.css`，图在 `site/charts.py`。

---

## 检查清单

| 检查 | 怎么做 |
|---|---|
| 终稿确实来自数据库 | 第 3 步用了 `--strict` 且没有报错 |
| 数字没变 | 重跑后 `git diff --stat */output/*.csv` 没有变化（或变化能解释） |
| 网页是最新的 | 页脚的构建日期；`--from-csv` 构建的页面页脚会标黄提示 |
| 代码没坏 | `uv run pytest` |
