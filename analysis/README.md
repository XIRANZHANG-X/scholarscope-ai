# 分析图表

五个分析方向的图都在这里。每张图配三样东西，方便接手修改：

| 文件 | 是什么 |
|---|---|
| `sql/figN_*.sql` | 取数的 SQL。**数据只从这里进图。** |
| `output/figN_*.csv` | 这条 SQL 的查询结果，也就是图上画的全部数据。可以直接用 Excel 或 Tableau 打开重画。 |
| `output/figN_*.png` | 图本身，200 dpi，可以直接放进 PPT。 |

**怎么运行、怎么改图，看 [`使用说明.md`](使用说明.md)。**
每个方向自己的 `README.md` 逐图说明了：画的是什么、CSV 每列的含义、图上能直接读出的事实、数据坑。

## 给仓库负责人：三条命令

都在仓库根目录执行，前提是数据库已经跑起来、台湾已经补入（步骤见 [`使用说明.md`](使用说明.md) 第四节）。

连数据库重新生成方向一到四的全部 CSV 和图：

```bash
uv run python analysis/run_all.py
```

方向五：

```bash
uv run python country_indicators_analysis/country_indicators_analysis.py
```

把五个方向各打成一个压缩包，发给对应的同学：

```bash
uv run python analysis/make_packages.py
```

压缩包生成在 `data/handoff/`（不进 git）。每个包解压后是一个能独立运行的文件夹：
脚本、SQL、CSV、图、说明都在里面，同学不需要仓库也不需要数据库。
同学改完发回的文件放回原位，再执行前两条命令，就得到来自数据库的终稿。

分析脚本用的是只读数据库连接，不会改动数据库里的任何东西。

## 所有图共用的约定

- **图上的文字是英文**，方便直接进 PPT；说明文档是中文。
- **空心圆点表示不完整的时期。** 2026 年的数据只到 9 月 22 日。
- **颜色跟着对象走。** 同一个方向里，同一个主题或类型在每张图上都是同一个颜色。
- **每张图下方的灰色小字**写明了数据来源、采集日期和统计口径。裁图时请保留。

## 所有方向都会碰到的数据坑

完整清单见 [`docs/数据字典.md`](../docs/数据字典.md)。和这些图直接相关的：

1. **2026 年只有不到 9 个月。** 比较年度总数时 2026 年会偏低，比较占比时影响小得多。
2. **41% 的论文没有国家信息**，而且预印本缺得最多。见方向三的图 6。
3. **会议论文进 OpenAlex 有几个月的滞后**，最近两个季度的会议论文数是偏低的。
4. **15.2% 的论文日期只精确到年**，被记成 1 月 1 日。按月或按季度画图前要剔除。
5. **LLM、Agents、Foundation models 只有计数没有论文**，而且是几个检索短语相加，是上限。
6. **Release 里的 `theme_year_counts.csv` 把 RAG 算了两遍。** 方向一用自己的 SQL，不受影响。
