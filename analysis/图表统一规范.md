# 图表统一规范（定稿）

五个方向共 35 张图都按这份规范出图。规范写在 [`common.py`](common.py) 里，是唯一的样式来源：
各方向的 `make_figures.py`（以及方向五的 `country_indicators_analysis.py`）只决定「画什么」，
字号、颜色、画布都从 `common.py` 读取。改样式请改 `common.py`，不要在单个脚本里另设。

---

## 1. 一张图一个坐标系

**不做多面板大图。** 原来的多面板图都已拆开或合并：

- 方向一：八个检索短语合并成一张（5 条线，只在末端标名称，没有图例）；四个主题的增长倍数共用一条坐标轴（fig2c）。
- 方向二：被引情况合并成两张分组柱（2024 深色、2025 浅色并排）；载体排行每种类型一张。
- 方向三：前 15 名国家拆成「论文数」「合作比例」两张；覆盖率拆成「按类型」「按年份」两张。
- 方向四：13 张子方向折线图和变化条形图合并成一张哑铃图。
- 方向五：每一对指标一张趋势图（「人均论文 vs 人口」与「论文总数 vs 人口」重复，不画）；模型图每个因变量一张。

## 2. 画布与导出

| 项 | 值 |
|---|---|
| 尺寸 | 13.33 × 7.5 英寸（16:9 幻灯片满页），放进 PPT 时不缩放 |
| 分辨率 | **300 dpi**，PNG 为 4000 × 2250 像素；同时导出同名 PDF（矢量） |
| 背景 | 白色 |
| 边距 | 固定（constrained layout），不用 `bbox_inches="tight"`，所以每张图尺寸完全一样 |

## 3. 字体

| 元素 | 字号 (pt) |
|---|---:|
| 图标题 | **20** |
| 坐标轴标题 | **16** |
| 坐标轴刻度 | **16** |
| 数据标签（柱端数值、线端标签、格子里的数字、点名标签） | **14** |
| 图例 | **14** |

- **所有文字加粗。** 字体 Segoe UI（Windows），回落 Helvetica Neue / Arial；中文回落微软雅黑 / 苹方。
- 对数轴的刻度写成 0.1 / 1 / 10 / 1,000，不用 10ⁿ（`common.plain_log_ticks`）。

## 4. 标题

- **居中**（相对整张图）。
- 是这张图的**简短概括**（正常的图标题，不写长结论），例如 `Papers per Year by Theme`、`International Co-authorship Share, Top 15 Countries`。
- **图中所有文字都是英文。**

## 5. 去掉的东西

| 去掉 | 原来的信息去哪里 |
|---|---|
| 背景网格线 | 数值靠数据标签读出 |
| 图下方的底注（来源、口径） | 写进各方向的 `README.md`；引用图时请一并说明口径 |
| 副标题 | 必要口径并入坐标轴标题，如 `Papers per year (log scale)`、`Year (2026* to 22 Sep)` |
| 上、右边框 | — |

## 6. 颜色

**同一个对象在所有图里颜色相同**（`common.COLORS`）：

| 对象 | 颜色 |
|---|---|
| RAG · Preprint | 蓝 `#2A78D6` |
| LLM · Conference paper | 橙 `#EB6834` |
| Agents · Article | 绿 `#1BAF7A` |
| Foundation models · Review | 黄 `#EDA100` |
| 数量大小（地图、热力图） | 单色蓝渐变（`common.SEQUENTIAL`） |
| 正负 / 高于低于预期 | 蓝 `#2A78D6` ↔ 红 `#E34948`，中点浅灰 |
| 宽口径 / 严口径（方向四） | 浅蓝 `#86B6EF` / 深蓝 `#256ABF` |
| 「其他」、对照、未记录 | 灰 `#A3A29D` |
| 互不相关的多个对象（如 15 个国家） | Nature 色板（`common.NATURE`，15 色，非渐变）；颜色只用来区分，没有含义 |

## 7. 高亮与特殊标记

- **最高 / 最低：粗黑描边 + 文字标注 Highest / Lowest。** 不用绿色（绿色是 Agents / Article）。
- **2026\* 只到 9 月 22 日：** 折线最后一段画虚线、末点空心；柱子画斜线填充；横轴写 `2026*`。
- **合作连线地图：** 前 5 对用深蓝粗线，其余浅蓝。
- **散点图的国家名：** 细引线连到对应的点，自动避开其他点、图例和别的标签（`common.label_scatter`）。

## 8. 线、点、柱

| 元素 | 规格 |
|---|---|
| 折线 | 3 pt（重点线 4 pt，例如 RAG） |
| 数据点 | 直径 9 pt，白色描边 |
| 柱子 | 槽位的约 60%，堆叠段之间 1.5 pt 白缝 |
| 图例 | 无边框，不压数据；能用末端标签时不用图例 |

## 9. 数据来源

- 图上的每个数都来自 `sql/*.sql`，经只读数据库连接查询。终稿用 `uv run python analysis/run_all.py --strict`
  生成（连不上库会报错，不会悄悄改用 CSV）。
- `--from-csv` 只用于不连库时调样式。
- 网页版（`site/build_site.py`）执行同一批 SQL，配色与口径和 PNG 一致；网页字号按屏幕缩小，图标题写在图外。
